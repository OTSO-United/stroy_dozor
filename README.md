# СтройДозор

Исходный код системы мониторинга строительной техники и сопоставления наблюдений с календарным планом.

## Состав

- `backend/` — FastAPI, обработка медиа, CV и фоновые задачи.
- `web/` — интерфейс React и статические ресурсы.
- `frontend/` — отдельный демонстрационный интерфейс.
- `contracts/` — схемы API и данных.
- `scripts/`, `deployment/`, `tests/` — служебный код и проверки.

## Модель

В репозитории находятся `models/yolo26m/best.onnx` и `manifest.json`. Docker-сборка проверяет модель на CPU. При замене весов необходимо обновить SHA-256 в manifest и проверить совместимость классов.

## Запуск

Сборка и запуск:

```powershell
docker compose build api
docker compose up -d --no-build --wait
```

Приложение доступно на `http://127.0.0.1:8080`. Настройки окружения приведены в `.env.example`.

Конфигурация доставки в `deployment/` не активируется автоматически. Для отдельного окружения её нужно настроить и проверить отдельно.
Публичный профиль Compose требует отдельной настройки домена и авторизации в Caddyfile.
